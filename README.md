# "Powered by Fortran" Logo

![](https://github.com/sebastian-mutz/powered_by_fortran_logo/blob/main/powered_by_Fortran.png)

Logo design iterations based on [Fortran Discourse discussion](https://fortran-lang.discourse.group/t/powered-by-fortran/11172/35).

- Uses same purple as the [community Fortran logo](https://github.com/fortran-lang/assets); should remind viewers of the logo.
- Uses DejaVu Sans Bold for "powered by" and the "toggle switch" design, as posted by Marc A. Jacobs (sharkbyte).
- Uses Clarendon font for "Fortran".
