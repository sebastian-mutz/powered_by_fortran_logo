# "Powered by Fortran" Logo

![](https://github.com/sebastian-mutz/powered_by_fortran_logo/blob/main/powered_by_Fortran_badge_1024x128.png)

The logo design was iterated in this [Fortran Discourse discussion](https://fortran-lang.discourse.group/t/powered-by-fortran/11172/35). 

- It uses same purple as the [community Fortran logo](https://github.com/fortran-lang/assets); it should remind viewers of the logo.
- It uses DejaVu Sans Bold for "powered by" and the "toggle switch" design, as posted by Marc A. Jacobs (sharkbyte).
- It uses the Libre Clarendon Wide (Medium Expanded) font for "Fortran".
