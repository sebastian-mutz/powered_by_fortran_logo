# "Powered by Fortran" Logo

The three versions of the logo (and their variants) were created based on the [Fortran Discourse discussion](https://fortran-lang.discourse.group/t/powered-by-fortran/11172/35). 

The following applies to all versions of the logo:

- It uses same purple as the [community Fortran logo](https://github.com/fortran-lang/assets).
- It uses DejaVu Sans Bold for "powered by".
- It uses the Libre Clarendon Wide (Medium Expanded) font for "Fortran".

## Versions

There are three versions of the logo, as shown below. For each version, there is an upper case ("Powered by") and lower case ("powered by") variant. The `badge` and `stacked` versions also have a frameless variant.
